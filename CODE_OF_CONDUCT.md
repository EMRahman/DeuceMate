# Code of Conduct

## The Short Version

Be respectful. Focus on the work. Don't be a jerk.

## The Longer Version

This is a small open source project run by one person in their spare time. The goal is to build a good tennis scoring app, not to manage interpersonal drama.

Expected behaviour:
- Critique code and ideas, not people
- Accept that maintainer decisions are final
- Give constructive feedback when reviewing others' PRs
- Be patient — this project is maintained on a best-effort basis

Not acceptable:
- Harassment, personal attacks, or discriminatory language
- Spamming issues or PRs
- Demanding features or fixes on a timeline

Issues or PRs that violate this will be closed without discussion. Repeated violations will result in being blocked from the repository.
