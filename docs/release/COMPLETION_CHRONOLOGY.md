# Completion chronology — release note

Completed matches now appear by finish date in history, Trends and comparisons.
A match started earlier and finished recently stays with the newest results,
including on the Watch. Recent Trends windows may change because they now
reflect finish order. Original start dates remain available in details and
multi-day reports. Opted-in unfinished Trends samples use last recorded activity
and are labelled provisional. No archive migration is required.

Confirmed play sessions now accompany explicit history resumes: point-anchored
graph/history markers, session summaries and text/AI/interactive/static reports.
Workouts start at each session's time, activity totals carry forward, and health
queries/lines/movement/coaching respect boundaries. Failed resume/park writes keep
the saved match available and show an error. Old archives decode with no invented
session history; mixed-version rewrites may drop unknown metadata. Physical-Watch
workout intervals and sensor collection remain pending release validation.
